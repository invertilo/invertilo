### About

Diseño backend y lógica web (APIs, auth, dominio), C++20 de bajo nivel, ingeniería inversa, y seguridad ofensiva/defensiva. Si el servicio tiene que aguantar y cerrarse bien, soy a quien conviene llamar.

I start from how a program holds state, speaks on the network, and protects itself — then I design the service, test where it yields, and close it.

---

### Craft

| Focus | What I do |
| --- | --- |
| **Backend & web logic** | HTTP contracts, domain rules, authn/authz, persistence, clear layer boundaries |
| **Systems & reverse engineering** | C++20, memory/binaries, high-performance overlays, integrity under load |
| **Security** | Both sides of the same problem: map the surface, then harden controls and telemetry |

Grey-hat here means studying the attack path to design the defense — not publishing recipes.
